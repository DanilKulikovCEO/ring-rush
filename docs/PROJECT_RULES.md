# Настройка проекта

## Подготовлено

Проект подготовлен под будущую мобильную 2D Idle-RPG игру про гонки и тюнинг. Код игры намеренно не добавлен, поскольку текущий запрос касается настройки папки и правил.

## Рекомендуемые локальные возможности

| Возможность | Назначение | Статус |
|---|---|---|
| `task-capability-routing` | Выбор минимального набора инструментов для задачи | Используется |
| `superpowers:brainstorming` | Уточнение игрового опыта и архитектурных решений перед разработкой | Доступен |
| `superpowers:writing-plans` | План реализации после согласования дизайна | Доступен |
| `superpowers:verification-before-completion` | Проверка результата перед отчётом о готовности | Доступен |
| `playwright` | Smoke-проверки браузерной версии и мобильных сценариев | Доступен |
| `imagegen` | Опциональные растровые ассеты при отдельном запросе | Доступен |

## Плагины и коннекторы

Для базовой реализации не нужны подключаемые приложения, аккаунты, сетевые API или внешние плагины. Достаточно локальных навыков и браузера. Подключение GitHub, Figma, Google Drive, Slack и других интеграций не планируется, так как они не добавляют ценности для самодостаточного HTML-файла.

## Будущая структура

```text
game/
├── AGENTS.md
├── README.md
├── docs/
│   └── PROJECT_RULES.md
└── index.html        # будет создан только отдельным запросом на реализацию
```

## Ограничения поставки

- Итоговая игра должна поставляться одним `index.html`.
- Внешние файлы, обязательная сборка и интернет-соединение не должны требоваться для запуска.
- Любые дополнительные файлы допустимы только для документации, тестов и локальных артефактов проверки.
- Реализация должна запускаться двойным кликом по HTML-файлу.
