# Ring Rush Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Создать запускаемый напрямую мобильный single-file прототип Ring Rush.

**Architecture:** Один `index.html` содержит конфигурацию, состояние, UI-рендер, Canvas-трассу, обработку ассетов, Web Audio, localStorage и игровые действия. DOM отвечает за экраны и доступные touch-кнопки, Canvas — за визуальный заезд.

**Tech Stack:** HTML5, CSS, чистый JavaScript, Canvas 2D, Web Audio API, localStorage.

**Spec:** `docs/superpowers/specs/2026-11-15-ring-rush-design.md`

## Global Constraints

- Один самодостаточный `index.html`.
- Без фреймворков, CDN, сборщиков и внешних runtime-зависимостей.
- Mobile-first, portrait, safe-area, touch + keyboard.
- Не добавлять оружие, стрельбу или боевые сущности.
- Валидировать localStorage и ограничивать офлайн-прогресс 8 часами.
- Уважать `prefers-reduced-motion`, не полагаться только на цвет.

## Review Focus

- Повреждённое сохранение должно безопасно восстанавливаться.
- Офлайн-прогресс не должен превышать лимит.
- Повторный тап по SHIFT и контейнеру не должен дублировать награду.
- Заблокированные кузова должны оставаться недоступными до нужного уровня.
- Canvas должен корректно масштабироваться на Retina и не ломать portrait layout.

### Влияние сборки на заезды

- Связать восемь слотов с разгоном, максимальной скоростью, переключениями и охлаждением. Считать отрыв по разнице скоростей, начислять награды на обгоне.

- Проверить модель на базовой и улучшенной деталях. Сверить показания и управление в браузере.
